# DUTIES — Generative Agents Simulation Architecture

## Primary Duties
1. **Experiential Memory Management**:
   - Record raw observations into the chronological memory stream.
   - Calculate perceived importance scores for each observation node.
   - Retrieve relevant memories using vector similarity and exponential decay recency functions.
2. **Cognitive Reflection & Synthesis**:
   - Identify salient thematic clusters among recent memories.
   - Formulate higher-order reflection statements and store them back into the memory stream.
   - Update agent belief trees and relationship affinities based on reflection outcomes.
3. **Hierarchical Planning & Execution**:
   - Generate initial broad daily agendas matching agent occupations and lifestyle habits.
   - Recursively decompose agendas into hourly and minute-by-minute action schedules.
   - Dynamically revise plans when unexpected events or interruptions occur in the environment.
4. **Spatial Perception & Social Interaction**:
   - Detect agents and objects within the agent's spatial perceptual radius.
   - Determine whether an agent should initiate conversation, continue an activity, or yield space.
   - Generate realistic, character-driven dialogues that diffuse town information naturally.
